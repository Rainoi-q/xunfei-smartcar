# simulation — 仿真环境

> **负责人：D**
> 对应功能⑭虚拟仿真交互，同时解决"只有一台车、四个人抢"的并行开发问题。

## 目标

1. 在 Gazebo 中搭一个**城市末端配送**场景，可完整演示一次取送货任务
2. 该场景同时作为 11 月 15 日前无车阶段的开发环境
3. 最终录制为功能⑭的演示镜头

## 场景要素

| 要素 | 说明 |
|---|---|
| 地面道路 | 黑色巡线 + 白色地贴 |
| 十字路口 | 带红绿灯模型（发光的彩色方块即可） |
| 货架区 | 若干货箱，贴二维码 |
| 投递点 | 地面方框，标记"3号门"等 |
| 障碍区 | 路锥 |
| 暗区 | 遮挡板，用于演示曝光自适应 |
| 墙体 | 围出街区轮廓 |

## 机器人模型

- 差速底盘 + 前视相机（发布 `/camera/image_raw`）
- 发布 `/odom`
- 接受 `/cmd_vel`
- 有 `base_footprint`、`base_link`、`camera_link` 三个 frame

## 验收标准

- [ ] `ros2 launch <本包> sim.launch.py` 能拉起场景与机器人
- [ ] 仿真机器人能沿黑线跑完一圈（复用 B 的巡线算法）
- [ ] Gazebo 中能看到红绿灯、货架、投递点
- [ ] 可录制 ≥ 30 秒的完整任务演示
- [ ] 关闭阴影、降低分辨率后帧率 ≥ 15 fps（虚拟机环境）
