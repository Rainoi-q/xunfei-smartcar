## 双通道设计（必须做）

比赛现场可能断网，**任何依赖云端的链路都要有离线兜底**：

| 环节 | 在线方案 | 离线兜底 |
|---|---|---|
| 语音识别 | 讯飞语音听写 API | 本地 Vosk 中文小模型 |
| 语义解析 | 讯飞星火 API | 本地 Qwen2.5-1.5B-Instruct |

启动时检测网络，不通则自动切换，并在 HUD 上提示当前模式。

## 语义解析的关键

不是"调 API 就完事"，评分看的是**多级语义**能力：

- 单指令：`去货架A`
- 多指令：`去货架A取货，然后送到3号门，最后回来`
- 带条件：`如果看到红灯就停，绿灯继续`
- 口语化：`帮我把那个蓝色的箱子拿到门口去`
- 否定/纠错：`不是A，是B`

**测试集必须覆盖这五类，共 30 条**，放在 `docs/data/nlp_test_cases.md`，
每周更新通过率，数据直接进 PPT。

## 验收标准

- [ ] 30 条测试指令通过率 ≥ 85%
- [ ] 3 条连续指令能顺序执行
- [ ] 断网后 5 秒内自动切换到离线模式
- [ ] 语音端到端延迟 ≤ 2 秒
