## 一、Topic 一览

| Topic | 消息类型 | 发布者 | 订阅者 | 说明 |
|---|---|---|---|---|
| `/camera/image_raw` | `sensor_msgs/Image` | camera_driver | vision_detect, lighting_adaptor | 原始图像（bgr8） |
| `/camera/set_exposure` | `std_msgs/Int32` | lighting_adaptor | camera_driver | 手动设置曝光绝对值（功能⑦） |
| `/camera/brightness` | `std_msgs/Int8` | lighting_adaptor | lighting_adaptor | 光照等级：0暗 / 1中 / 2亮 |
| `/scan` | `sensor_msgs/LaserScan` | range_driver | obstacle_avoider | 雷达/超声波测距 |
| `/odom` | `nav_msgs/Odometry` | base_driver | line_follower, parking, mission_manager | 里程计 |
| `/perception/line` | `std_msgs/Float32` | vision_detect | line_follower | 轨迹横向偏移（-1.0~1.0，正为偏右） |
| `/perception/traffic_light` | `smartcar_msgs/TrafficLight` | vision_detect | mission_manager | 红绿灯颜色与置信度 |
| `/perception/qr_payload` | `std_msgs/String` | vision_detect | mission_manager | 二维码解析出的 JSON 字符串 |
| `/perception/debug_image` | `sensor_msgs/Image` | vision_detect | 调试（rqt_image_view） | 可视化调试图，`debug=true` 时发布 |
| `/perception/objects` | `smartcar_msgs/DetectedObjects` | vision_detect | mission_manager | 货物/投递点检测结果 |
| `/perception/ocr_text` | `std_msgs/String` | vision_detect | mission_manager | OCR 识别文本 |
| `/voice/text` | `std_msgs/String` | voice_input | nlp_planner | 语音转写文本 |
| `/nlp/task_plan` | `smartcar_msgs/TaskPlan` | nlp_planner | mission_manager | 结构化任务序列 |
| `/mission/state` | `std_msgs/String` | mission_manager | 全部（HUD显示） | 当前任务状态 |
| `/cmd_vel` | `geometry_msgs/Twist` | line_follower / obstacle_avoider / parking | base_driver | 底盘速度指令 |
| `/gripper/command` | `std_msgs/Bool` | mission_manager | gripper | true=抓取，false=释放 |

## 二、自定义消息

### TrafficLight.msg

```
std_msgs/Header header
uint8 UNKNOWN=0
uint8 RED=1
uint8 YELLOW=2
uint8 GREEN=3
uint8 color
float32 confidence
uint32 area_px
bool valid
```

| 字段 | 说明 |
|---|---|
| color | 灯色，取常量值 |
| confidence | 0.0—1.0 |
| area_px | 目标像素面积，用于过滤远处误检 |
| valid | 本帧是否检测有效；false 时其他字段无意义 |

### DetectedObject.msg / DetectedObjects.msg

```
string label
float32 confidence
int32 x_min
int32 y_min
int32 x_max
int32 y_max
```

`DetectedObjects` = `std_msgs/Header header` + `DetectedObject[] objects`。

### TaskCommand.msg

```
string action        # go / grab / drop / wait / speak / stop
string target        # 货架A / 3号门 / 红绿灯
float32 distance     # 未知填 -1.0
string raw_text      # 对应原文片段，便于溯源
```

### TaskPlan.msg

```
std_msgs/Header header
uint8 PENDING=0
uint8 RUNNING=1
uint8 DONE=2
uint8 FAILED=3
string raw_command
TaskCommand[] commands
uint8 status
int32 current_index
string message
```

## 三、语义解析输出约定（功能②③）

`nlp_planner` 必须把自然语言转成如下结构的 `TaskPlan`：

输入：`把A货送到3号门，然后回来`

输出：

```json
{
  "raw_command": "把A货送到3号门，然后回来",
  "commands": [
    {"action": "go",   "target": "货架A",  "distance": -1.0, "raw_text": "把A货送到3号门"},
    {"action": "grab", "target": "A货",    "distance": -1.0, "raw_text": "把A货送到3号门"},
    {"action": "go",   "target": "3号门",  "distance": -1.0, "raw_text": "把A货送到3号门"},
    {"action": "drop", "target": "3号门",  "distance": -1.0, "raw_text": "把A货送到3号门"},
    {"action": "go",   "target": "起点",   "distance": -1.0, "raw_text": "然后回来"}
  ],
  "status": 0,
  "current_index": 0,
  "message": ""
}
```

**测试要求**：至少准备 30 条真实指令，覆盖单指令、双指令、带条件、带否定、口语化五种类型，录入 `docs/data/nlp_test_cases.md`，每周更新通过率。

## 四、二维码 JSON 约定（功能④）

一条二维码需包含多个字段，用于体现"多信息解析"：

```json
{
  "order_id": "A03",
  "consignee": "张三",
  "destination": "3号门",
  "priority": 2,
  "weight_kg": 1.5
}
```

`/perception/qr_payload` 直接发布这段 JSON 字符串。

## 五、状态机约定（mission_manager）

```
IDLE ──收到TaskPlan──> PLANNING ──> NAVIGATING ──> GRABBING ──> DELIVERING ──> DONE
                          │              │             │            │
                          └──────────────┴─────────────┴────────────┴──> FAILED ──重试──> NAVIGATING
```

`/mission/state` 发布格式（供 HUD 显示，纯文本）：

```
STATE=NAVIGATING | TASK=2/5 | TARGET=3号门 | ELAPSED=45s
```

## 六、调试 HUD 约定（A负责）

屏幕左上角固定显示：

```
[任务] 前往货架A → 取货 → 送至3号门
[状态] 巡线中 | 速度 0.30 m/s | 里程 2.4 m
[识别] 红绿灯:绿(0.94) | 二维码:A03-张三-3号门 | 货物:纸箱(0.88)
[光照] 中(亮度88) | 曝光值120
[耗时] 本轮 01:23
```

HUD 直接进演示视频，务必保持信息可读、字号够大。
